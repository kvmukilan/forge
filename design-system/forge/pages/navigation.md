# Navigation override

The shell must reduce choice, not merely restyle it.

- Desktop shows Today, Quests, Character, Journey, and Rewards as one calm primary group.
- A single `Library` disclosure contains planning, social, economy, and collection destinations in labeled groups.
- Settings stays pinned near the account/utility area, not mixed with feature navigation.
- Mobile shows Today, Quests, Character, Journey, and More. More opens a grouped bottom sheet; it is not a 4-column icon wall.
- Active state uses a small violet indicator, stronger text, and a subtle surface. Avoid full-height colored rails and glow effects.
- Every row is at least 44px tall, has an icon and label, and preserves direct URLs.
- Bottom padding uses `env(safe-area-inset-bottom)` and main content reserves the bar height.
